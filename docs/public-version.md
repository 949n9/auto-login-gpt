# 公用版本维护约定

本仓库面向独立安装，不依赖既有服务器网络、生产文件路径或交接容器。应用与网页登录分别构建，Nginx 只发布 HTTPS 入口；账号数据和会话数据分卷保存。

## 接口与状态

- Sub2API 推送使用 `concurrency`、`priority`；CRS 使用 `concurrencyLimit`、`weight`
- 并发和优先级经服务端校验后保存并写入对应平台请求；账号级及批量 CRS 设置共用同一字段组件
- `POST /api/jobs/:id/rest` 手动静置，`POST /api/jobs/:id/retire` 移入废号区并要求 `reason`
- 移动操作按邮箱串行，拒绝与正在执行的任务、安全变更、未确认推送及定时任务并行
- 静置记录持久化在已有加密库，不伪造上游登出事实；仅完整登录成功可解除状态
- CRS 推送队列在实际提交前重新核对账号状态；Sub2API 推送期间保留账号锁定标记

## 验证

`npm test` 覆盖配置、保存、双平台导入、授权状态、手动静置、重启恢复与登录入口认证。界面检查覆盖授权名称、优先级提交、单个与批量移动，使用本地合成账号。

改动运行行为时补充对应回归；不使用真实账号来触发密码、TOTP、登出或 OAuth 操作。公开提交仅包含源码、合成测试与配置模板。
